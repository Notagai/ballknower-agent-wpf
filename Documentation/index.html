CAPABILITIES

More than a chat box.

Useful tools, thoughtful details, and a desktop experience designed to stay out of your way.

✦

AI chat & local memory

Integrated AI chat with local conversation context, keeping your ongoing thread close at hand.

⌁

Your key, protected

Bring your own API key. Saved credentials are protected with Windows DPAPI.

⌘

Practical desktop tools

Create, read, edit, delete, and move files. Create shortcuts and open applications.

◐

Adaptive & blurred UI

Adaptive colors respond to the desktop background, with blur for a soft glass-like window.

▤

Markdown & web search

Readable Markdown responses, clickable links, and internet search support for the assistant.

✧

Motion with a purpose

Smooth animations and a clean, blurred interface. Prefer less motion? Use /see.

⌗

Stay in your flow

/pin and /unpin control visibility while you Alt-Tab between apps.

⌨

Global keyboard shortcut

Bring Ballknower back with the configured modifier + Windows key shortcut (default Alt+Win). If it stops responding, run Ballknower.exe again—the background process may have stopped.

↺

Commands that get out of the way

/clear resets the conversation. Command autocomplete helps you find built-in commands.

◈

Deliberately uncluttered

A cohesive interface that reveals what you need, when you need it—without unnecessary panels.
