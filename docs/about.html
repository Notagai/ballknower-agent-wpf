A DESKTOP COMPANION

About.

Ballknower brings AI closer to the work you're already doing: a floating interface, configurable models, quick commands, and desktop-oriented tools.

AI that stays in your flow

Instead of making you switch into another full-size app, Ballknower is designed as a lightweight overlay you can bring forward when needed and keep out of the way when you're done. Its visual treatment is intentionally compact and desktop-friendly.

Ballknower is a Windows application built with WPF and .NET 8.

From a question to an action

Use the chat for questions, brainstorming, and task-oriented requests. Depending on the request and the tools enabled, the assistant can work with local text files, connected Google Drive files, launch applications, or search the web. Spoken responses can be handled by ElevenLabs or the built-in Microsoft speech engine.

Slash commands provide direct controls for the app, while autocomplete helps you discover built-in commands and your own configured shortcuts.

Designed to be configured

  • Choose your AI provider: configure Groq, OpenRouter, OpenAI, or Gemini, along with your model and API key.
  • Speech output: select ElevenLabs or Microsoft, fetch ElevenLabs voices and models, choose a speaker, and adjust app-only speech volume.
  • Google Drive: connect and test a Google account to enable supported Drive workflows.
  • Shape the conversation: enable streaming and adjust the conversation-history budget.
  • Build your shortcuts: map command names to applications or executables you use often.
  • Quick access: configure the global modifier + Windows key shortcut.
  • Advanced options: an optional first-message prompt and web-search-only tool restriction.

Privacy and control

Ballknower uses a bring-your-own-key model. Saved API credentials and Google Drive OAuth tokens are protected locally with Windows DPAPI. Ballknower speech volume adjusts the app audio signal rather than intentionally changing Windows master volume. Requests to AI and speech providers use the services you configure; review their policies and pricing before use.

Desktop tools can affect files and applications, so pay attention to the requested action and any confirmation prompts. The app's tool restrictions and settings determine which capabilities are available.
